# 🌐 Portfolio Website

**Link:** https://mariia-moroz.netlify.app/

This is my personal **portfolio website**, built to showcase my projects, skills, and experience as a developer. The site combines modern frontend technologies with smooth animations and interactive 3D elements.

---

## 🚀 Tech Stack

-   **HTML5 & CSS3** → Semantic structure and responsive layouts
-   **React.js** → Core framework for building the application
    -   **High-Order Components (HOC)** → Code reusability and modular architecture
    -   **React Router** → Dynamic page routing and smooth navigation
    -   **Dynamic Rendering** → Efficient rendering of components based on data/state
-   **Tailwind CSS** → Utility-first styling for clean and scalable design
-   **Three.js** → Interactive 3D models, animations, and visual effects

---

## ✨ Features

-   **Modern UI/UX** with responsive design
-   **Dynamic content rendering** for an optimized user experience
-   **Reusable components** through HOCs to ensure consistency and maintainability
-   **3D interactive elements** and animations powered by Three.js
-   **Smooth navigation** using React Router
-   **Clean and scalable codebase** with Tailwind CSS utilities

---

## 📂 Structure

-   `src/components` → Reusable UI components and sections of the portfolio
-   `src/assets` → Images, icons, and static resources
-   `src/constants` → Objects with info for dynamic rendering of elements (cards, links, etc)
-   `src/utils` → Helper functions, higher-order components, etc.

---

## 🎯 Purpose

The goal of this project is to demonstrate:

-   My ability to build **modern, responsive web applications**
-   Knowledge of **React ecosystem** (HOCs, Router, dynamic rendering)
-   Experience in creating **interactive and engaging UI** with **3D graphics**

## 🛠️ Installation & Setup

1.  Clone the repository:
    ```
    bash
    git clone https://github.com/your-username/portfolio.git
    cd portfolio
    ```
2.  Install dependencies:

    ```
    npm install
    ```

3.  Start the development server:

    ```
    npm start
    ```

4.  Build for production:

    ```
    npm run build
    ```
